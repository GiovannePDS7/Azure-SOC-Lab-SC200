# Simulações

Simulações controladas usadas para validar telemetria e detecções no ambiente
isolado do laboratório, que já foi removido.

- [Falhas de autenticação](T1110-autenticacao/README.md): RDP, SSH e Entra ID.
- [Criação de conta local](T1136.001-conta-local/README.md).
- [PowerShell](T1059.001-powershell/README.md).
- [Tarefa agendada](T1053.005-tarefa-agendada/README.md).
- [Alterações de privilégios](abuso-de-privilegios/README.md): Entra ID e Azure RBAC.

O [diário de simulações](../documentacao/attack-journal.md) reúne horários e
resultados. Em uma recriação, execute testes somente em recursos autorizados e
isolados, registre o horário e remova as alterações e os artefatos ao final.
