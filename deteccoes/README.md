# Detecções

Conteúdo de detecção do laboratório, incluindo consultas KQL, configuração de regras
analíticas e documentação de ajustes. Antes da implantação, valide as consultas de
acordo com o esquema do workspace de destino.

- [Índice de regras analíticas](regras-analiticas/README.md): as oito regras registradas no export fornecido e os links para suas descrições.
- [Catálogo KQL](consultas-kql/README.md): consultas organizadas por tabela de origem.
- [Export ARM do Sentinel](regras-analiticas/azure-sentinel-analytics-rules.json): export parametrizado fornecido para este laboratório. Antes da implantação, consulte o [registro da implantação](../documentacao/lab-build-record.md), inclusive a divergência documentada na configuração RDP.
