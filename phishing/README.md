# Análise de phishing

Dois exercícios usam mensagens sintéticas para praticar triagem estática:

- [Caso 01](caso-01/analysis.md): mensagem que simula coleta de credenciais.
- [Caso 02](caso-02/analysis.md): fraude de fornecedor com troca de dados de pagamento.

Os indicadores e as limitações estão nas análises. O
[script de triagem](../scripts/README.md) processa arquivos `.eml` sem executar seu
conteúdo. Não inclua anexos maliciosos ativos, credenciais ou dados pessoais.
